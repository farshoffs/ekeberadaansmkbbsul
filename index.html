Lokasi belum dibenarkan

Benarkan lokasi pada peranti untuk menggunakan Rekod Waktu.

iPhone / iPad: Settings → Privacy & Security → Location Services → hidupkan Location Services. Pilih eKeberadaan (jika ada) atau Safari Websites, gunakan While Using the App dan Precise Location. Jika menggunakan Safari, semak juga Settings → Apps → Safari → Location → Allow. Kembali ke aplikasi dan tekan Cuba semula.
Android: Hidupkan Location dalam Quick Settings. Pergi ke Settings → Apps → eKeberadaan (jika tersenarai) atau Chrome → Permissions → Location → Allow only while using the app serta Use precise location (jika tersedia). Dalam Chrome, buka ⋮ → Settings → Site settings → Location; pastikan eKeberadaan tidak disekat. Pilih Allow while visiting the site apabila diprompt, bukan Allow this time.
Aktifkan Location/GPS dalam tetapan peranti. Kemudian benarkan akses lokasi untuk laman eKeberadaan dalam tetapan pelayar dan tekan Cuba semula.
